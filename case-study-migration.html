AI & Data Platform · JPMorgan Chase · Aug 2024 – Aug 2026

Automating a 4-million-record bank consolidation

Software Analyst, Full-Time. When Corporate Banking consolidated into Commercial & Investment Banking, I owned the migration pipeline and built two AI tools that permanently removed manual lookup work for other teams.

The problem

Corporate Banking was consolidating into Commercial & Investment Banking — a reorganization that touched roughly four million cost centers spread across multiple environments. Beyond the raw migration, two second-order problems showed up immediately: Finance had no way to check migration status without pinging an engineer directly, and the team's documentation had grown into a Confluence space so large that finding anything meant asking someone who'd been there long enough to remember where it was.

What I built

Migration orchestration. Used Apache Airflow and Python scripts to orchestrate the cost-center migration across environments in a controlled, auditable way rather than a manual, environment-by-environment push.

An AI-agent chatbot for migration status. Finance no longer needed to file a request and wait — the chatbot gave instant, consolidated status lookups on demand, replacing a manual process that didn't scale with four million records in flight.

A RAG assistant over the team's Confluence space. Crawled and chunked every page, embedded the chunks, and served natural-language Q&A over the result — so "where's the doc on X" became a question you could just ask, instead of a hallway conversation.

Infrastructure work alongside the migration:

  • Migrated a legacy application to AWS ECS on Java 17.
  • Streamlined Airflow DAGs' EMR usage to cut per-run compute cost.
  • Sped up 5GB+ transfers with an S3 multipart upload strategy.
  • Designed an end-to-end Java service (controller/service/repository layers, token-based client-to-client auth) consolidating two legacy profitability applications into GBIQ, and separately built a CBCMP profitability report and ETL pipeline reconciling post-merger data.
  • Engineered a PII data-masking pipeline — field-level redaction plus SHA-based hashing, upgraded over time from SHA-1 to SHA-2 to SHA-3 — run on every production-to-UAT refresh.
The chatbot and the RAG assistant solved the same underlying problem in two different shapes: someone needs an answer that currently only exists in a person's head or a wall of documentation. That pattern is why this site's own build process leaned on the same idea — grounding an assistant in a fixed body of content instead of a person's memory.
